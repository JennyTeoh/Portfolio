# Jenny Teoh: Portfolio

A static site (HTML + CSS, no build step). All images are stored locally in `/images`, so the site keeps working even if access to Figma, Framer or Klaviyo changes.

## Edit
- **Contact links:** open `index.html`, find `EDIT YOUR CONTACT LINKS HERE` near the bottom, and add your email and LinkedIn.
- **Copy:** every piece of text is plain HTML in `index.html`.
- **Images:** replace files in `images/` and keep the same names, or update the `src=` values.

## Publish (GitHub Pages)
1. Go to the repo on GitHub, then **Settings → Pages**.
2. Under Source, choose **Deploy from a branch**, then select `main` and `/ (root)`.
3. The site goes live at `https://jennyteoh.github.io/Portfolio/`.

GitHub Pages on a free plan needs a public repo. To keep the repo private, connect it to Netlify or Vercel instead. Both are free and will serve the same files from a private repo.
